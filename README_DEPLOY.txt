Deploy railway dashboard on Streamlit Community Cloud.

1. Place your real analysis_result.csv next to app_08.py.
2. Upload app_08.py, requirements.txt, and analysis_result.csv to the root of your GitHub repository.
3. Visit https://share.streamlit.io and connect GitHub.
4. Create app -> select repository, branch main, file app_08.py -> Deploy.
5. Do not upload confidential internal data to a public repository.
